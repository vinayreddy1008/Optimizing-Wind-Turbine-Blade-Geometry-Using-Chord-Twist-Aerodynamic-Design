# Optimizing Wind Turbine Blade Geometry Using Chord–Twist Aerodynamic Design

This project optimizes the chord and twist distributions of a wind turbine blade using a simplified Blade Element Momentum (BEM) aerodynamic model. Airfoil lift/drag data and wind-speed profiles are taken from published journal sources. The objective is to maximize Annual Energy Production (AEP) under realistic geometric and manufacturability constraints.

## Project Structure
- `src/` — Python code (BEM implementation and optimizer)
- `docs/` — Documentation and reference PDF(s)
- `notebooks/` — Jupyter notebooks for experiments
- `examples/` — Sample configurations
